# Tecnoi
 
**AI Products. Engineering Expertise.**
 
Tecnoi is an information technology company based in Istanbul, Türkiye. We build
and operate the infrastructure that production software runs on — DevOps
platforms, databases, and AI systems — and we develop our own products on top of
that experience.
 
[tecnoi.com.tr](https://tecnoi.com.tr) · [LinkedIn](https://www.linkedin.com/company/tecnoi-tr) · info@tecnoi.com.tr
 
---
 
## What we do
 
**Platform engineering** — Kubernetes and container platforms, cluster design and
migration, CI/CD and GitOps pipelines, observability.
 
**Databases** — PostgreSQL, MySQL, MongoDB and Redis: architecture, replication,
high availability and disaster recovery, performance tuning, security hardening.
 
**AI infrastructure** — model serving, MLOps lifecycle, GPU workload scheduling
on Kubernetes.
 
**Managed services** — 24/7 operations and AIOps for the systems we build.
